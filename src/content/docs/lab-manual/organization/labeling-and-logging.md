title: Labeling & logging
description: How we name and label freezers, boxes and drawers, and how to log a new box.
---

Everything in the lab that is stored gets a short code. Plasmids have their own page: see [Plasmids](/lab-manual/organization/plasmids/). The code identifies a **thing**, not where it is: locations are recorded separately, so a label stays valid when something moves.

## Storage equipment

Each fridge and freezer has a code made of a two-letter prefix and a two-digit number.

| Prefix | Storage | Example |
|---|---|---|
| **RF** | Refrigerator, +4 °C | RF01 |
| **FZ** | Freezer, −20 °C | FZ01 |
| **UL** | Ultra-low freezer, −80 °C | UL01 |
| **LN** | Liquid nitrogen | *(scheme to be decided, see below)* |

The temperature is part of the prefix, so a box filed in the wrong kind of unit is visible at a glance.

**Door label.** Two lines: the code large on top, a short description below it.

> **UL01**  
> Ultra-low freezer, −80 °C

The code is what people read and type, so it is the dominant element. The description tells a new person what they are looking at without opening the door. Labels are printed, not handwritten, and the adhesive must be rated for the unit (check this for −80 °C doors). We do not use barcodes on equipment.

**Drawers and shelves.** The label on the drawer says only the drawer number, for example **D1**, because the unit is already identified by its door. In the inventory the full location is written **RF01-D1**. Use one numbering direction everywhere. If a unit already has printed or embossed shelf numbers, use those.

**Taking a unit out of service.** Keep the old label on the unit, record the change, and note where the contents were moved.

## Boxes

Each box has its own ID, **BX** plus four digits (**BX0001**), with no location in it. Which freezer, drawer or shelf a box sits in is a separate record, so moving a box is a single edit and the label never changes.

## How to log

The lab inventory spreadsheet is kept outside the website. *(Link to be added for lab members.)*

### A new box

1. Take the next free number from the box list and write it down as **BX00xx**.
2. Print the label and attach it to the box.
3. Add the box to the box list with its location, for example **UL01-D2**.

### Moving a box

Change the location of the box in the box list. Do not change anything on the vials or the box label.

- **Drawer numbering direction.** Top to bottom is the default unless a unit has its own numbers.
